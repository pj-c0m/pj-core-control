# AGENTS.md

## Назначение

Этот репозиторий содержит статический Dashboard PJ-CORE Control.

## Обязательные правила

- Не переносить данные проектов внутрь `index.html`.
- Единственный runtime-источник состояния: `data/projects.json`.
- Не добавлять секреты.
- Не ломать запуск через Docker Compose.
- После любых изменений проверять валидность JSON и открытие Dashboard.
- Сохранять адаптивное уменьшение карточек по `lastActivity`.
- Не считать просмотр карточки новой активностью.
- Закреплённые проекты не должны автоматически уменьшаться.
- Все пользовательские тексты и документация ведутся на русском языке.

## Команды проверки

```bash
python3 -m json.tool data/projects.json >/dev/null
docker compose config
docker compose up -d --build
curl -f http://127.0.0.1:8088/
curl -f http://127.0.0.1:8088/data/projects.json
```
